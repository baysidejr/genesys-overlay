# Genesys symbol font

`genesys.woff2` comes from [D1SoveR/genesys-dice-roller](https://github.com/D1SoveR/genesys-dice-roller) and is licensed under the GNU General Public License v3.0. It draws official-style Genesys dice symbols from letters: `s` success, `a` advantage, `t` triumph, `f` failure, `h` threat, `d` despair.

It reached this repo by way of baysidejr/genesys (`client/public/fonts/genesys.woff2`).
